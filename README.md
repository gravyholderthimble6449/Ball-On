## 🌍 About the Technology

Ball-On is built with a modern tech stack designed for reliability and performance:

- **Frontend:** Next.js (React) with TypeScript for blazing-fast user interfaces
- **Backend:** Python for data processing and machine learning models
- **Machine Learning:** Scikit-learn for transfer value prediction algorithms
- **Database:** PostgreSQL via Supabase for secure, scalable data storage
- **Data Sources:** Historical and current football data from Transfermarkt and other public football datasets

This blend of technologies ensures Ball-On delivers accurate insights with a smooth user experience whenever you open it.
